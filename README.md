# Resume Verification System

A Java Swing desktop application with MySQL database for automated resume analysis and verification.

## 📋 About This Project

This system automates resume verification by checking for essential details like contact information, education, skills, and experience. It then generates a score (0-100) and detailed report.

## ✨ Key Features

- User login with database authentication
- Upload or paste resume content
- Automated verification algorithm
- Score calculation (0-100)
- Store all data in MySQL database
- View history of all uploaded resumes
- Analytics dashboard

## 💻 Technologies Used

- **Frontend:** Java Swing
- **Backend:** Java
- **Database:** MySQL
- **Tools:** IntelliJ IDEA, MySQL Workbench
- **Connectivity:** JDBC
